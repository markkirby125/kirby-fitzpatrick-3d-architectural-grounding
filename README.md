## Core Patterns

- **3D Architectural Grounding**: 3D Grounding Protocol: require explicit definition of (1) Memory Lifecycle, (2) Concurrency Model, and (3) Failure Modes before code generation.
- **Practical Application**: Defeating 'Korean Chicken Fluency' (superficially valid code that fails in production).
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
